Download manager

grabbit

Parallel, resumable downloads for Linux, with the tedious parts of free hosters — wait timers, captchas, multi-part archives — handled for you.

View the repo →
  • Splits each file across several connections and resumes cleanly after a pause, crash, or reboot
  • Watches your clipboard and queues links the moment you copy them
  • Waits out hoster countdown timers and solves captchas in a real browser window, then carries that session into the download
  • Groups multi-part archives into one package with combined progress
  • One control API over MCP and HTTP/JSON-RPC drives everything the desktop app can do

Agent interaction hub

qq

A desktop interaction hub for AI agents: when one needs a decision, a credential, or just wants to say it's done, a card appears over whatever you're doing, answered in one keystroke.

View the repo →
  • A short sound tells you what kind of thing arrived before you even look
  • Every option on a card has a number, so the whole exchange is one keystroke
  • Twenty tools over MCP, the same twenty as a CLI for shell scripts, hooks, and cron
  • Local only: no cloud, no account, nothing leaves the machine

Capture & annotation

snapper

A Linux-first screenshot tool with a fully non-destructive editor — every annotation stays a reselectable object, saved as a re-editable project instead of a flattened PNG.

View the repo →
  • Freeze-frame capture overlay keeps the selection and magnifier pixel-perfect
  • Every annotation is undoable, restylable, and re-editable, saved as a .snap project
  • Annotation colors adapt automatically so they read on any background
  • Full capture history with OCR search over past screenshots
